📚 Metodologias Ágeis e Scrum no Desenvolvimento Web

Este repositório contém os artefatos do projeto acadêmico desenvolvido para o curso de Tecnologia da Informação do Centro Universitário UNA.

O trabalho aborda a contribuição das metodologias ágeis, com ênfase no framework Scrum, para o planejamento, organização e desenvolvimento de aplicações web.

📂 Arquivos e Artefatos do Projeto

Abaixo estão descritos os arquivos que compõem este repositório:

📄 Artigo Acadêmico

Arquivo: Artigo Acadêmico - Metodologias Ágeis e Scrum no Desenvolvimento Web (1).pdf

Documento principal da pesquisa, que aborda os valores ágeis, os componentes do Scrum e apresenta um cenário hipotético de um portal de tarefas para demonstrar a aplicação prática do framework.

🎨 Protótipo Visual (Figma)

Como artefato midiático deste trabalho, foi desenvolvido um protótipo visual de um Sistema de Gestão Scrum.

O objetivo é representar visualmente a organização de projetos, Product Backlog, Sprints e tarefas, demonstrando como o framework Scrum pode ser aplicado em um sistema web.

🎯 Objetivo do Projeto

Demonstrar a importância das metodologias ágeis no desenvolvimento de aplicações web, destacando o Scrum como framework para organização de equipes, gerenciamento de atividades, planejamento de Sprints e acompanhamento da evolução de projetos.
